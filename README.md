# Карты для Кладезя

Здесь лежат карты для программы [«Кладезъ»](https://github.com/Leon-Kladez/kladez). Это бесплатная библиотека знаний, которая работает без интернета.

Карты выкладываются в **выпусках** (Releases) этого репозитория:
- файлы `.pmtiles`: федеральные округа России, страны СНГ, Европы, Ближнего Востока и Северной Америки, у каждого региона есть подробный и обзорный вариант;
- `maps.json`: список карт, который читает Кладезъ (`…/releases/latest/download/maps.json`);
- `.torrent` к каждому файлу, чтобы его можно было скачать и раздавать торрентом.

Скачивать вручную ничего не нужно: Кладезъ берёт карты сам, через «Настройки → Управление картами».

## Как собираются карты

Раз в квартал сборка на GitHub (`.github/workflows/build-maps.yml`):
1. берёт свежую сборку мировой карты [Protomaps](https://protomaps.com);
2. вырезает регионы по границам из `tools/maps-build/regions.json`;
3. выкладывает файлы и обновлённый `maps.json` в новый выпуск.

Сборку можно запустить и вручную (Actions → «Сборка карт»). По умолчанию она только оценивает размеры. Собирать можно частями: уже выложенные регионы остаются в списке.
